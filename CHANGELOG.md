# Changelog

## 0.4.0 (2026-09-25)

- Prebuilt downloads for Windows, macOS (Apple Silicon and Intel) and Linux on
  every tagged release, with a `SHA256SUMS.txt` file.
- New `--help` and `--version` flags, so the binary can be checked from a
  terminal without opening the window.
- Linux builds now pick the X11 and Wayland windowing backends explicitly.
- CI builds and tests on Windows, macOS and Linux.
- The crate version now matches the release tags (it was left at 0.1.0).
